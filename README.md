# Ship Design Studio（船舶概念設計Webアプリ）

GitHub Pagesで公開することを想定した、ブラウザ動作の初期プロトタイプです。

## 含まれている機能
- 主要寸法入力（全長・幅・型深さ・喫水・水密度）
- 船首・船尾の形状プリセット
- 3D概念モデルと平面・側面・正面の簡易図
- 構造部材の基本情報の登録・削除
- 排水量の簡易概算と入力警告
- ブラウザ内保存、JSON書き出し・読み込み
- PC・スマートフォン向けのレスポンシブ画面

## 重要な制限
この段階の3D船体形状・2D図は概念表示です。排水量は実形状を積分した値ではなく、方形係数0.62を仮定した概算です。構造強度、安定性、規則適合、DXF/STEP/STL/OBJ出力は未実装です。船舶の安全性や建造用設計を保証するものではありません。

3D表示にはThree.jsをCDNから読み込みます。3D機能の利用にはインターネット接続が必要です。

## ローカルで試す
`index.html` をブラウザで開いてください。ブラウザの設定によってはローカルファイルからの読み込みに制限が出るため、その場合はVS CodeのLive Server等を利用してください。

## GitHub Pagesで公開する
1. GitHubで新しいリポジトリを作成します（例：`ship-design-studio`）。
2. このフォルダ内の `index.html`、`style.css`、`app.js`、`README.md` をリポジトリ直下へアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source** で **Deploy from a branch** を選択します。
5. Branchを `main`、Folderを `/(root)` にして **Save** を押します。
6. Pagesの画面に公開URLが表示されるまで待ちます。URLは通常 `https://ユーザー名.github.io/リポジトリ名/` の形です。

公開リポジトリのファイルとWebページは一般に公開されます。個人情報や機密設計データをリポジトリへ入れないでください。設計JSONはアプリからダウンロードして個別に保管してください。
